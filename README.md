# Disease Frequency Analysis — Python & Pandas

Analyzes weekly disease case data using Python and Pandas to identify trends in common diseases: Flu, Dengue, Typhoid, and COVID-19.

## Tools Used
Python, Pandas, Matplotlib, Jupyter Notebook

## Project Steps
- Data loading and exploration (df.describe(), df.info())
- Sorting to identify diseases with highest case counts
- Disease frequency analysis using groupby()
- Visualization of case distribution with Matplotlib

## Key Insights
- Flu had the highest total number of reported cases
- Dengue had the lowest frequency among the diseases analyzed
- Weekly trends show clear variation across diseases
